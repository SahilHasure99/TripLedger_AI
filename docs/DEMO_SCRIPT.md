# 3-Minute Hackathon Demo Script

**0:00 – Hook (15 s)** "Planning a trip takes five apps and you never know the true cost. TripLedger AI puts discovery, planning, budget and payment in one place."

**0:15 – Discover (40 s)** Home → let the marquee and aurora play → type `Kyo` → suggestion appears → search `Goa` (any place works) → open Google Maps.

**0:55 – Plan (50 s)** Open Bali → submit with pace *Packed* → show the "travel buddy" card → results: flights, hotels with Maps/photos links, weather, itinerary → **Budget Snapshot** (flip the budget low to show the overspend warning) → export PDF.

**1:45 – Pay (50 s)** Account → register → My trips → save trip → Payments → create sandbox checkout → approve → capture. Say: *"The browser never chooses the amount — the server checks it against the saved trip and again against PayPal."*

**2:35 – Trust (20 s)** Ledger → export CSV. Show replay is harmless. Mention rate limiting, revocable tokens, escaped output, tests.

**2:55 – Close (5 s)** "Beautiful to explore, rigorous with money."

### Pre-demo checklist
API + Streamlit running · sandbox keys in `.env` · one pre-registered account · browser at 100 % zoom · fallback screenshots in case Wi-Fi fails.
